## 遇到的問題
1. 【壞掉】公告與規章頁 → 想一次把兩則公告標為已看過 → 滑鼠點擊「全部標為已看過」按鈕
   完全無反應（含重新整理後再點一次）→ 改用鍵盤 Tab＋Enter 才成功。一般不熟悉鍵盤操作
   的員工會以為這顆按鈕故障，永遠留著 2 則未讀。
2. 【壞掉】休假申請頁 → 想選「假別＝病假」→ 滑鼠點開下拉並點選項目後，欄位仍顯示
   「請選擇」（選取沒有生效）→ 改用鍵盤方向鍵＋Enter才成功。與問題 1 是同一種
   「滑鼠點擊在這幾個原生下拉／按鈕上不觸發選取」的模式，值得後端／前端一起檢查是否
   共用了同一段有問題的事件處理邏輯。
3. 【難用】休假申請頁的日期欄預設值是「今天」（2026-08-30，星期日），要幫忙選好未來
   日期（2026-08-31）之後，若沒注意到，第一次嘗試送出時會被系統擋下並顯示
   「所選時段落在上班時間之外，請改選 09:00 至 18:00 之間的區間」——這句提示沒有明講
   問題其實出在「日期還是今天、不是你要請假的那天」，容易讓人誤以為是時間格式錯誤而
   不是日期錯誤。
4. 【建議】休假申請與我的休假頁下方都有一行「依據：特休 勞動基準法第38條」，但無論
   選的假別是特休還是病假，這行文字都固定顯示「特休」，沒有隨著實際選擇的假別（本次
   是病假）換成對應法條（例如勞基法第 43 條或性別平等工作法等）。看起來像是共用元件
   沒有把假別參數帶進去，容易讓人誤以為病假也是引用特休那條法規。
5. 【建議】請款申請頁送出時沒有附收據，系統沒有跳出任何「未附收據」的提醒或確認，
   直接允許送出成功。頁面下方雖然平時就寫著「收據單檔上限 25.0 MB，送出後仍可在
   『我的請款』補附」，但這句話是固定顯示，不是針對「你這次沒附」而跳出的提醒，
   容易讓人送出後就忘記要回頭補附收據。
6. 【問題，暫時無法定位原因】在完成第 4 步（Enter 標記已看過）後，我用瀏覽器直接重新
   整理公告頁面想再次確認結果，卻整個掉回登入畫面（session 似乎消失），需要重新輸入
   帳密登入。重新登入後打卡狀態（上班中、05:38:49）與剛才標記已看過的結果都完整保留，
   所以不是資料遺失，比較像是那次重新整理剛好撞上一次 session 校驗失敗的偶發狀況；
   之後同樣的操作（直接網址重新整理）沒有再重現，未達到「連續三次失敗」門檻，
   記錄下來但未進一步追查根因。

## 找路紀錄
- 「補登打卡」第一直覺：點左側「打卡」畫面，往下捲動找到「逐日明細」表格，才發現說明文字
  寫「點時間或空格可以補登或調整」，直接點格子裡的「—」就會展開輸入列——沒有另外一顆
  獨立的「補登申請」按鈕，靠這句小字才找到入口。
- 「請病假」第一直覺：左側「休假申請」，一次就找到，表單結構清楚（假別、從、到、事由）。
- 「請款不附收據」第一直覺：進「請款申請」後看到「收據」那一欄旁邊寫「沒有選擇檔案」，
  猜測跳過它直接按「送出請款單」即可，一次成功，沒有卡關。
- 「查我的薪資單」第一直覺：左側「查詢紀錄」分組下的「我的薪資單」，一次找到。

## 一般員工視角的評價
- 「我的薪資單」空狀態文案（「尚無薪資單。每期薪資算完後在本頁出現。」）看三秒就懂，
  不會誤以為系統壞掉。
- 「我的加班」空狀態（「尚未送出加班申請。」）同樣一看就懂。
- 打卡頁「補登申請」沒有獨立入口按鈕，靠一行小字提示要點表格裡的空格，第一次用的人
  很可能完全找不到（如果沒仔細讀那行灰字，會以為漏打卡就沒辦法補了）。
- 休假申請表單被系統擋下時顯示「所選時段落在上班時間之外，請改選 09:00 至 18:00 之間
  的區間」，這句話讓人以為是「幾點到幾點」填錯，看不出真正原因是「日期還停在今天」，
  算是文案沒對準真正的問題所在。
- 沒有遇到「知道要做但找不到按鈕」的情況——8 個查詢畫面與 3 個申請表單都在側邊欄一次
  找到，沒有繞路。
- 沒有看到講「電腦內部狀態」而非「講我的事」的文案；「審核中」「等簽核」「待確認會計
  科目」這幾個狀態詞都是站在申請人角度講「現在誰要處理」，讀得懂。

## UI 易懂度評分：3 / 5
理由：大部分畫面（打卡、休假申請、請款申請、個人專區、各查詢頁）文案清楚、空狀態
說明到位，找路不困難。扣分主要是因為本次遇到兩個會直接影響信任感的互動缺陷——
滑鼠點擊在「全部標為已看過」按鈕與「假別」下拉選單上完全沒有作用，一般使用者不會
想到要改用鍵盤，很可能會誤以為系統當機或自己操作錯誤而放棄，這種等級的問題足以讓
一個原本設計清楚的系統在第一印象上顯得不可靠。
