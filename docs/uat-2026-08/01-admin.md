## 遇到的問題

### 【難用】首次設定精靈的「部門」步驟一次只能建一個
在哪一頁：首次設定精靈 步驟3「部門」。
我想做什麼：一次建立管理部、業務部、技術部三個部門。
實際發生什麼：畫面上只有一個「部門名稱」欄位加「建立並繼續」按鈕，填完「管理部」按下去，系統直接前進到步驟4「上下班時間」，沒有「新增下一個部門」的選項，也沒有任何文字提示「其餘部門可以之後在基礎設定頁面補建」。
我怎麼繞過：先讓精靈跑完全部 7 步驟進入系統後，在左側選單「基礎設定」頁面往下捲，找到「部門」區塊裡的「新增部門」按鈕，把業務部、技術部補上。
建議：精靈步驟3要嘛允許連續新增多筆（像「建立」後欄位清空、留在本步驟直到按「下一步」），要嘛至少在畫面上寫一句「還可以到基礎設定新增更多部門」，不要讓人以為只能建一個。

### 【難用/建議】沒有獨立的「人資」角色，人資只能跟會計共用同一個角色
在哪一頁：帳號管理 → 建立帳號 的「角色」下拉選單，以及角色與核准 → 權限對照表。
我想做什麼：老闆的紙條寫「人資：林雅婷」，想在建立帳號時選一個對應人資職務的角色。
實際發生什麼：角色下拉只有「系統管理員、負責人、會計、出納、主管、會計師、一般職員」七個選項，沒有「人資」。到「角色與核准」的權限對照表查證，發現「看人資資料」「人事異動與請假」「執行薪資作業」「看薪資彙總」這些人資相關權限，整張表只有「負責人」和「會計」打勾，出納／主管／會計師／一般職員全部沒有。
我怎麼繞過：只能把林雅婷也設成「會計」角色，這樣她確實能管人資，但同時也拿到開立傳票、過帳、應收應付、稅務試算等全套財務權限——超過她實際需要的範圍。
建議：如果人資本來就該由會計兼管，畫面上可以在建立帳號選「會計」時順帶說明「此角色同時涵蓋人資職掌」，讓人資選對角色時不會猶豫；如果人資與會計本該分開，就該开一個只給人資權限（看人資資料、人事異動與請假、執行薪資作業）但不给開立傳票/應收應付的角色。

### 【難用】公司資料沒有地址、電話欄位
在哪一頁：首次設定精靈 步驟1「公司資料」，以及事後的「基礎設定」→「公司與帳務」卡片。
我想做什麼：把老闆紙條上的地址（台北市信義區信義路五段7號）與電話（02-8101-8800）填進公司資料。
實際發生什麼：兩處都只找得到公司名稱、統一編號、會計年度起始月份、記帳本位幣等欄位，全系統目前沒有地方可以填地址或電話。
我怎麼繞過：沒有繞過，這兩項資料目前存不進系統，先記在這份筆記裡。
建議：若地址、電話本來就不在這版產品規劃內，那就不是缺陷；但若統一發票、公文往來將來需要它，建議在公司資料補上這兩個欄位。

### 【難用】會計與會計師兩個角色名稱容易選錯
在哪一頁：帳號管理 → 建立帳號的角色下拉。
我想做什麼：幫陳美玲選一個「會計」職務的角色。
實際發生什麼：下拉選單同時有「會計」與「會計師」兩個很像的選項，一開始沒點開「看完整權限對照表」我很難分辨兩者差異（後來查表才知道「會計師」多了可以直接調整已過帳分錄、刪除誤開傳票這類更高權限，比較像簽證會計師/資深角色，「會計」才是一般內部會計人員）。
我怎麼繞過：點了「看完整權限對照表」連結去查權限矩陣才確定選「會計」是對的。
建議：下拉選單本身如果能像選定角色後那樣即時顯示一句白話說明（畫面上其實已經有做這件事，只是要先選了才看得到），或乾脆在下拉的選項文字後面加一個簡短註記，就不必跳頁查表。

## UI 易懂度評分

**4 / 5**。整體來說，作為第一天上班、完全沒看過系統的 IT 人員，這套系統的首次設定流程走起來算順：精靈把公司資料、銀行帳戶、部門、上下班時間、外部登入、負責人帳號拆成清楚的七個步驟，每一步都有明確的下一步／略過按鈕，存檔都有 toast 回饋；建立帳號後臨時密碼會用醒目的警告框強調「只顯示一次、請立即交付」，帳號列表也會標記「未變更初始密碼」，這些細節讓人放心不會漏掉關鍵資訊。扣分主要在於：(1) 部門只能一次建一個、精靈完成頁空白，這類「流程斷點」需要自己摸索去別的頁面才能完成任務；(2) 角色設計上「人資」沒有獨立位置，只能跟會計共用，如果不是自己主動點開「權限對照表」查證，很容易搞不清楚哪個角色才是對的。

**「知道要做這件事，但找不到按鈕在哪」的畫面**：有，就是首次設定精靈步驟3「部門」。走完那一步以為部門只能建一個，直到我自己想到去「基礎設定」頁面往下捲才在很下面的位置找到「新增部門」按鈕——這中間有一段時間完全不知道業務部、技術部要去哪裡建。
