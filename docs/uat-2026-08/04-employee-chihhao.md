## 遇到的問題

1. 【壞掉】公告與規章頁「全部標為已看過」按鈕點了沒有效果。點擊後（含用滑鼠座標點、用 find 工具取 ref 精準點兩種方式各試一次）畫面仍顯示「有 2 則還沒看過，已展開」，兩則公告的「新」標籤沒有消失；切到別頁再切回來，未讀計數依然是 2。沒有任何錯誤訊息或提示，就是靜靜地沒有作用。這是唯一該按的動作卻按不動的地方。

2. 【難用】休假申請的「假別」下拉選單用滑鼠點選項選不動。點開下拉後，看著畫面點在「特休」文字上，結果選單收起、值仍是「請選擇」，游標反而落到旁邊的日期欄。改用鍵盤（方向鍵＋Enter）才選得到「特休」。原生 `<select>` 選單用滑鼠點選項失敗，是本次測試中唯一一個「用滑鼠點不動」的下拉，記錄下來但沒有繞過去（照樣走鍵盤這條路完成任務，因為說明允許鍵盤等同打字）。

3. 【建議】公告內文（規章制度〈出勤與請假管理辦法〉正文）有錯字：「二、遲到寬段」應為「遲到寬限」；「未經核准不得自行談假」的「談假」應為「請假」。這是會被畫面讀出的正式文案，值得訂正。

4. 【建議】我的 MCP 頁面核發出來的 Token 明文框旁沒有「複製」按鈕，只寫「請立即複製保存」，要自己選取文字複製；同一頁下方「連線方式」的「位址」欄卻有現成的「複製」按鈕。兩處待遇不一致，Token 更重要、更該有一鍵複製。
